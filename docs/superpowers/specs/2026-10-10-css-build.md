# CSS build module

The approved architecture review consolidates CSS compilation and delivery in one module. The user approved one owner for classification, Sass imports, minification and delivery, with full recompilation on CSS changes rather than caching or selective builds.

- `build/css.js` exposes only `setupCssBuild(config)` to Eleventy.
- A single `eleventy.before` hook compiles SCSS entrypoints from files; filenames starting with `_` are partials.
- `critical` and `base` write to the configured includes directory's `css/`; other entrypoints write to the configured output directory's `css/`.
- All entrypoints use consistent relative, source-directory and package import resolution. Production output is minified with CleanCSS.
- Watch source CSS and exclude generated includes from watching. Sass errors fail the build.
- Preserve Eleventy, Sass, Nunjucks, Node >=24 and the absence of a bundler.
- Test actual Eleventy builds and watch behavior through the same setup interface, using temporary fixtures and real compilers.
- Update project packages to current stable versions compatible with Node 24, regenerate the pnpm lockfile, and validate lint, tests and production output.

No redesign content or visual changes are included. Existing development builds do not emit usable source maps, so introducing maps is outside this change.
