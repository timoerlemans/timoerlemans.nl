# CSS Build and Package Updates Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Execute inline; use a fresh reviewer for the completed change.

**Goal:** Consolidate CSS build behavior and update packages without changing page presentation.

**Architecture:** One `setupCssBuild(config)` function owns an Eleventy before-build hook and CSS watching. Tests run real builds against temporary projects.

**Tech Stack:** Eleventy 3, Sass, CleanCSS, Nunjucks, pnpm, Vitest, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-10-css-build.md`

## Global Constraints

- Node >=24; keep Sass, Eleventy and no bundler.
- Preserve current inline and emitted stylesheet destinations.
- Preserve the source checkout's existing `.gitignore` edit and the separate redesign worktree.
- No extra compiler adapters, caching or selective compilation.

## Review Focus

- Configured includes/output paths: generated CSS must follow actual Eleventy directories.
- Watch loops: generated include writes must not perpetually trigger rebuilds.
- Shared/package imports: both delivery paths must resolve identically.
- Production minification: errors must fail the build rather than emit broken styles.
- Updated major versions: Markdown attributes, navigation tests and site generation must still work.
